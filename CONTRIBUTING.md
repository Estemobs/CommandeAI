# Contribution

Merci de vouloir contribuer à CommandeAI !

## Développement

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python commande_ai.py
```

## Vérifications avant PR

```bash
python -m compileall -q .
```

## Pull requests

1. Décrivez le problème résolu et testez la commande `.devoir` dans un serveur de test.
2. Gardez la PR petite et ciblée.
3. Référencez l'issue concernée dans la description.
